{% blocktranslate with site_name=SITE_NAME %}I presenti Termini e Condizioni (di seguito "Termini") regolano l'utilizzo del sito web altesiasuite.com (di seguito "il Sito") e le condizioni di prenotazione dei servizi di ospitalità offerti da {{ site_name }} (di seguito "la Struttura").{% endblocktranslate %}

{% translate "2. Definizioni" %}

  • {% blocktranslate %}"Ospite": la persona che effettua una prenotazione{% endblocktranslate %}
  • {% blocktranslate %}"Prenotazione": la richiesta di soggiorno confermata dal pagamento dell'acconto{% endblocktranslate %}
  • {% blocktranslate %}"Acconto": il 30% dell'importo totale del soggiorno, dovuto al momento della prenotazione{% endblocktranslate %}
  • {% blocktranslate %}"Saldo": il restante 70% dell'importo totale, da corrispondere al check-in{% endblocktranslate %}
  • {% blocktranslate %}"Unità": l'alloggio prenotato (suite, appartamento, camera){% endblocktranslate %}

{% translate "3. Prenotazioni" %}

{% translate "3.1 Come prenotare" %}

{% blocktranslate %}Le prenotazioni possono essere effettuate tramite il Sito seguendo la procedura guidata. La prenotazione è confermata al ricevimento del pagamento dell'acconto.{% endblocktranslate %}

{% translate "3.2 Requisiti" %}

  • {% translate "L'Ospite deve avere almeno 18 anni di età" %}
  • {% translate "Sono richiesti dati di contatto validi (email e telefono)" %}
  • {% translate "Il numero di ospiti non può superare la capienza massima dell'unità" %}
  • {% translate "È richiesto un soggiorno minimo (indicato nella scheda dell'unità)" %}

{% translate "3.3 Conferma" %}

{% blocktranslate %}Dopo la prenotazione riceverai un'email di conferma con il riepilogo del soggiorno e il numero di prenotazione. Ti invitiamo a conservare questa email.{% endblocktranslate %}

{% translate "4. Prezzi e Pagamenti" %}

{% translate "4.1 Prezzi" %}

{% blocktranslate %}I prezzi indicati sul Sito sono per notte e possono variare in base alla stagione e al periodo. Il prezzo totale include il costo del soggiorno e le eventuali pulizie finali. L'importo esatto è calcolato e mostrato prima della conferma della prenotazione.{% endblocktranslate %}

{% translate "4.2 Acconto" %}

{% blocktranslate %}Al momento della prenotazione è richiesto il pagamento di un acconto pari al 30% del totale del soggiorno. Il pagamento avviene tramite Stripe, un sistema di pagamento sicuro e certificato PCI DSS Level 1.{% endblocktranslate %}

{% translate "4.3 Saldo" %}

{% blocktranslate %}Il saldo (70% rimanente) dovrà essere corrisposto al momento del check-in, con le modalità che saranno comunicate dalla Struttura.{% endblocktranslate %}

{% translate "4.4 Fatturazione" %}

{% blocktranslate %}Per richiedere fattura, è necessario comunicare i dati fiscali al momento della prenotazione o al più tardi al check-in.{% endblocktranslate %}

{% translate "5. Cancellazione e Rimborsi" %}

{% translate "5.1 Cancellazione da parte dell'Ospite" %}

  • {% blocktranslate %}Oltre 30 giorni prima del check-in: rimborso completo dell'acconto{% endblocktranslate %}
  • {% blocktranslate %}Da 15 a 30 giorni prima del check-in: rimborso del 50% dell'acconto{% endblocktranslate %}
  • {% blocktranslate %}Meno di 15 giorni prima del check-in: nessun rimborso dell'acconto{% endblocktranslate %}
  • {% blocktranslate %}No-show (mancata presentazione): nessun rimborso{% endblocktranslate %}

{% translate "5.2 Cancellazione da parte della Struttura" %}

{% blocktranslate %}La Struttura si riserva il diritto di cancellare una prenotazione in caso di forza maggiore, problemi tecnici all'immobile o altre circostanze eccezionali. In tal caso, l'Ospite riceverà il rimborso integrale dell'acconto e, dove possibile, una proposta di date alternative.{% endblocktranslate %}

{% translate "6. Check-in e Check-out" %}

  • {% blocktranslate %}Check-in: dalle ore 15:00 alle ore 20:00{% endblocktranslate %}
  • {% blocktranslate %}Check-out: entro le ore 10:00{% endblocktranslate %}

{% blocktranslate %}Orari diversi possono essere concordati previo contatto con la Struttura, compatibilmente con la disponibilità. Il check-in tardivo (dopo le 20:00) deve essere comunicato in anticipo.{% endblocktranslate %}
